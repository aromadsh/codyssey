## 4) 검증 방법
#### a. 터미널 조작 명령어 사용
- 폴더(디렉토리) 생성
```
mkdir [생성 디렉토리 명]
```

- 폴더(디렉토리)로 이동
```
cd [이동하려는 디렉토리 명]
```

- 현재 경로 확인
```
pwd
```
